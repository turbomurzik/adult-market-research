# Research Track 02 — Adult Games

## Working hypothesis

A metadata-first discovery layer for adult games may be more defensible than a download mirror or forum clone.

Potential positioning:

**IMDb + Steam + Reddit for adult games.**

## Current anchors

- F95Zone: very large destination audience and high direct traffic.
- Existing adjacent discovery/download sites demonstrate substantial demand.

## Product primitives to investigate

- canonical game pages
- developer pages
- tags / genre / art style / engine / platform
- latest version
- update history
- development status
- screenshots/trailers where permitted
- reviews
- recommendations
- follow game / follow developer
- release notifications
- developer claim/update flow
- support/purchase outbound links

## Core moat hypothesis

Structured catalogue + developer identity + update graph + user follows.

## Key constraint

Avoid making piracy/download mirroring the core value proposition. Rights, metadata provenance and linking policy need to be designed deliberately.
